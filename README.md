# Textimony.io

Textimony is private message evidence software for organizing large SMS, iMessage, WhatsApp, Android, and email exports into searchable timelines, participant maps, quantified indicators, reviewable evidence, and verifiable reports.

Live site: [https://textimony.io](https://textimony.io)

## What Textimony Does

Textimony helps reviewers turn long message records into source-linked evidence timelines. The live product is built for sensitive message review workflows where source context, participant mapping, redaction, evidence windows, and report exports need to stay connected.

Public Textimony pages describe:

- message evidence timelines
- participant maps
- source-linked report packets
- behavioral evidence metrics
- upload and review workflow methodology
- redacted sample evidence packets
- trust, privacy, and security controls
